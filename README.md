# Trainee 2026/2 — Telemetria

Repositório destinado à organização das atividades e dos projetos desenvolvidos durante o programa Trainee 2026/2 da área de Telemetria do Projeto Solares.

## Objetivos

- Organizar os exercícios e as atividades do trainee.
- Registrar o aprendizado e o desenvolvimento técnico dos participantes.
- Armazenar códigos, experimentos e documentação.
- Acompanhar as etapas e entregas do programa.
- Incentivar boas práticas de programação e colaboração.

## Organização

Os arquivos serão organizados conforme as atividades e os módulos definidos ao longo do programa, facilitando o acesso aos materiais e o acompanhamento das entregas.

## Contribuições

As contribuições devem seguir as orientações da equipe de Telemetria, mantendo os arquivos organizados, o código legível e a documentação clara.
