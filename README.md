# Trainee 2026/2 — Telemetria Solares ☀️⛵

Repositório central para o versionamento de código e entrega das atividades do processo seletivo de Telemetria do Projeto Solares.

⚠️ **Atenção:** Todas as especificações técnicas, regras de negócio, etapas do desafio e critérios de avaliação estão detalhados **exclusivamente** no edital oficial. Consulte o arquivo **`Telemetria Trainee Solares.pdf`** anexado a este repositório antes de iniciar.

## 📂 Organização do Repositório

Para facilitar a avaliação e manter o código limpo, sugerimos estruturar as pastas do seu repositório da seguinte forma:

* `/firmware` — Códigos C++/Arduino desenvolvidos para o ESP32.
* `/backend` — Servidor REST, lógica do banco de dados e WebSockets.
* `/frontend` — Interface gráfica e Dashboard em TypeScript.
* `/docs` — Relatórios, diagramas ou imagens extras do Tinkercad/protoboard.

## 🚀 Diretrizes de Entrega

1. **Commits Constantes:** Faça commits frequentes e com mensagens claras. O histórico do Git é um dos critérios para avaliarmos sua organização e evolução ao longo das semanas.
2. **Gestão no Notion:** O GitHub armazena o código, mas o acompanhamento do seu progresso e a gestão das tarefas devem ser atualizados continuamente no seu Notion.
3. **Hardware Seguro:** Qualquer imprevisto ou dano aos componentes físicos da bancada deve ser reportado imediatamente aos avaliadores.

Em caso de dúvidas, utilize nossos canais oficiais de comunicação. Bom desafio! ⚡
